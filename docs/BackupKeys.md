# Формат резервной копии ключей шифрования (E2EE)

Для обеспечения безопасности переписки в мессенджере Penik используется сквозное шифрование (E2EE). Все секретные ключи хранятся исключительно локально на клиентском устройстве в базе данных IndexedDB (`penik-messenger`).

Резервная копия ключей экспортируется в виде файла в формате **JSON**. Этот файл содержит полную копию локального удостоверения пользователя, необходимую для расшифровки старых сообщений и продолжения общения с новых устройств.

## Структура файла бэкапа (`penik_keys_backup_[username].json`)

Файл представляет собой JSON-объект со следующими полями:

```json
{
  "ik_priv_jwk": {
    "kty": "OKP",
    "crv": "X25519",
    "x": "...",
    "d": "...",
    "key_ops": ["deriveKey", "deriveBits"],
    "ext": true
  },
  "ik_pub_raw": [ ... ],
  "spk_priv_jwk": {
    "kty": "OKP",
    "crv": "X25519",
    "x": "...",
    "d": "...",
    "key_ops": ["deriveKey", "deriveBits"],
    "ext": true
  },
  "spk_pub_raw": [ ... ],
  "spk_sig": [ ... ],
  "user_id": 123
}
```

### Описание полей

| Поле | Тип | Описание |
| :--- | :--- | :--- |
| `ik_priv_jwk` | `Object` | Приватный ключ идентификации (Identity Key, IK) в формате **JWK (JSON Web Key)**. Используется как основа E2EE-протокола X3DH. |
| `ik_pub_raw` | `Array<Number>` | Публичный ключ идентификации в виде сырого массива байт (32 байта). |
| `spk_priv_jwk` | `Object` | Приватный подписанный ключ предподписки (Signed Prekey, SPK) в формате **JWK**. |
| `spk_pub_raw` | `Array<Number>` | Публичный подписанный ключ предподписки в виде сырого массива байт (32 байта). |
| `spk_sig` | `Array<Number>` | Цифровая подпись ключа предподписки, подтверждающая, что он принадлежит владельцу Identity Key (64 байта). |
| `user_id` | `Number` | Числовой идентификатор пользователя на сервере, к которому привязаны данные ключи. |

---

## Технические детали ключей

* **Алгоритм**: X25519 (ECDH на эллиптической кривой Curve25519).
* **Сырые публичные ключи (`ik_pub_raw`, `spk_pub_raw`)**: Массивы из 32 чисел (байт), сериализуемые из `Uint8Array`.
* **Приватные ключи в формате JWK (`ik_priv_jwk`, `spk_priv_jwk`)**:
  * `kty`: тип ключа (`OKP` — Octet Key Pair).
  * `crv`: используемая эллиптическая кривая (`X25519`).
  * `x`: публичная координата (Base64URL-encoded).
  * `d`: секретный множитель / приватная компонента (Base64URL-encoded). **Должен оставаться в секрете!**

## Безопасность файла бэкапа

> [!WARNING]
> Этот файл содержит ваши **приватные (секретные) ключи шифрования**. 
> Любой человек, получивший доступ к этому файлу, сможет читать вашу переписку и отправлять сообщения от вашего имени.
>
> **Храните файл бэкапа в зашифрованном или защищенном хранилище и никогда не передавайте его третьим лицам.**
